# Fleet Module — Fleet Manager Guide

## Daily command

- **Fleet Dashboard** / **Reporting & Automation** — KPIs (OOS, defects, WOs, cost, replacements).
- **Readiness Board** — incomplete / failed checks.
- **Fleet Defects** — critical defects and reserve requests.
- **Cost & Replacement** — score fleet, generate capital plan.

## Capital & procurement

1. Score assets under **Cost & Replacement**.
2. Generate 10-year capital plan.
3. Open **Fleet Procurement** for requests → specs → build → commissioning.
4. Bind apparatus insurance before in-service.

## Risk

Use **Accident & Risk** for collisions, claims, roadside, and preventability reviews. Sensitive findings are restricted.

## Cutover from classic

Keep classic Apparatus / Maintenance until Migration Center reports reconcile cleanly, then enable cutover flags in Configuration Studio.
