# Fleet Module — Operator Guide

## Checks

1. Open **Readiness Board**.
2. Start a check for your unit (published checklist version is snapshotted).
3. If offline, answers save to a local draft; sync when connectivity returns.
4. Failed critical items create defects / may force OOS per policy.

## Defects

Report defects from the Defects module or after a failed check. Mark severity accurately — critical defects escalate.

## Operations

- Assignments, transfers, pool reservations, load plans, and decon are under **Fleet Operations**.
- Do not place an OOS unit in service from CAD; maintenance status is authoritative in Fleet.

## Fuel

Log fuel on **Fuel & Energy**. Exception rules flag odd quantities / sites.
