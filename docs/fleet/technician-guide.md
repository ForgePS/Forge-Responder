# Fleet Module — Technician Guide

## Work orders

1. Open **Fleet Work Orders**.
2. Add labor hours/rates and parts; actual cost rolls from lines when set.
3. Track downtime hours when units are OOS for repair.
4. Close with QC notes when required.

## PM & tests

- **PM Forecast** shows due / overdue schedules (deduped auto-WO).
- **Fleet Tests** records certifications (hose migrate available from classic).

## Components

Tires, batteries, fluids, recalls, and warranties live under **Components & Warranty**. Complete recall matches with reviewer confirmation.

## Shops & vendors

Configure shops/vendors in Configuration Studio. Vendor portal (external) is out of scope for this release — use department shop boards.
