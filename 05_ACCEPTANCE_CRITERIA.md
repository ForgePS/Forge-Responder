# Acceptance Criteria

## Build Must Pass
- `npm install`
- `npm run build`
- App loads without white screen
- Existing hydrant page still works

## Branding
- Main header says: Horn Lake Fire/EMS Dashboard
- Theme uses Horn Lake Command style
- No primary HAVOC OPS branding on internal dashboard
- Optional footer may say: Powered by Havoc Calls

## Layout
- Desktop-first design
- Top command bar exists
- Left navigation exists
- Dashboard uses top KPI row
- Dashboard uses 3-column layout
- No large live incident map

## Navigation
Must include pages or placeholders for:
- Dashboard
- Personnel
- Certifications
- Training
- Scheduling
- Shift Trades
- Apparatus
- Assets
- Maintenance
- Hose Testing
- Occupancies
- Inspections
- Preplans
- Hydrants
- Documents
- Analytics
- Administration
- Incidents
- EMS Reports
- Fire Reports
- Compliance Export

## Design Quality
- Professional command staff appearance
- Clean cards
- Consistent tables
- Clear status badges
- No neon/glow-heavy cyberpunk design
- Usable on 1920x1080 desktop

## RMS Priority
The app should clearly prioritize:
1. Personnel
2. Certifications
3. Scheduling
4. Training
5. Fleet
6. Assets
7. Documents
8. Prevention
9. Analytics

Incident reporting should not dominate the UI.
